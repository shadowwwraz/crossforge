## 1. Цель и контекст

Реализовать социальный компонент **«YOUR SQUAD»** (как на референсном скриншоте) в виде выдвижной боковой панели в интерфейсе CrossForge:
- Отображение участников текущего лобби в реальном времени (аватар, статус онлайна, имя, живое векторное превью прицела).
- Возможность в один клик скопировать/экипировать прицел тиммейта (`🪄`).
- Возможность в один клик предложить/отправить свой прицел тиммейту (`✈️`).
- Подключение без логина и пароля: вход по короткому коду лобби (например, `CF-7429`) через P2P WebRTC DataChannel (PeerJS).
- Встроенные демо-тиммейты (*ShadowByte*, *VortexSurge*, *VoltByte*, *CrimsonRed*, *NovaBlade*) для тестирования UI при игре в соло.

## 2. Архитектура и поток данных

```
  +-------------------------------------------------------+
  |                   CrossForge UI                       |
  |  +-------------------------------------------------+  |
  |  | SquadDrawer (Выдвижная панель справа, ~300px)   |  |
  |  | - Заголовок: 👥 YOUR SQUAD [Код лобби: CF-842]  |  |
  |  | - Список участников (You + Peers)               |  |
  |  |   * Мини-канвас векторного превью прицела       |  |
  |  |   * Аватар + онлайн точка + имя                 |  |
  |  |   * Кнопки: 🪄 (Equip) / ✈️ (Send)              |  |
  |  | - Футер: [Invite Friends] / [Join Squad] / Leave |  |
  |  +-------------------------------------------------+  |
  +--------------------------|----------------------------+
                             |
                   Squad Service / Hook
              (Local State + WebRTC PeerJS)
                             |
             +---------------+---------------+
             |                               |
       [Host Mode]                     [Client Mode]
     Создаёт код CF-XXX             Подключается к CF-XXX
     Принимает подключения         Синхронизирует свой прицел
```

### Протокол сообщений (WebRTC DataChannel):
- `SYNC_STATE`: отправка своего текущего `CrosshairSpec`, никнейма и цвета аватара при входе или изменении прицела.
- `OFFER_CROSSHAIR`: целевое предложение прицела конкретному участнику (`✈️`). Получатель видит интерактивный тост: *«(Имя) предлагает прицел "(Название)". Принять? [Да / Нет]»*.
- `OFFER_ACCEPTED`: подтверждение применения.

### Локальный профиль игрока:
В `shared/types.ts` в `Settings` добавляется секция:
```ts
profile: {
  nickname: string; // по умолчанию 'You' или имя из ОС
  color: string;    // цвет кружка аватара (#8B6BFF, #C6FF3D, #FFD166 и т.д.)
}
```

## 3. Пользовательский интерфейс (UI & Компоненты)

1. **Кнопка в Header (`src/components/Header.tsx`):**
   - Кнопка `👥 Squad` с динамическим бейджем количества участников (например, `1` или `5`), открывающая `SquadDrawer`.
2. **Панель `SquadDrawer.tsx` (`src/components/SquadDrawer.tsx`):**
   - Тёмный стиль *Forge Lab* (`#12141B`, волосяные границы `rgba(236,233,222,.08)`, тёплый текст).
   - Строка участника:
     - Квадратная плашка 38×38 px с тёмным фоном и живым `MiniCrosshairCanvas`.
     - Круглый аватар 28×28 px с первой буквой ника и индикатором онлайна (зелёная точка).
     - Текст: ник (жирным) + подпись *«Using "Название"»* или *«Using custom crosshair»*.
     - Кнопки действий для тиммейтов:
       - `🪄` — моментально применяет чужой прицел к себе с тостом *«Прицел скопирован»*.
       - `✈️` — отправляет свой прицел данному тиммейту.
3. **Модальное окно подключения (`JoinSquadModal`):**
   - Ввод 6-значного кода комнаты для подключения к другу.
4. **Кнопка `Invite Friends`:**
   - Генерирует код лобби (если еще не создан) и копирует в буфер обмена текст: *«Присоединяйся к моему скваду в CrossForge: CF-XXXX»*.
